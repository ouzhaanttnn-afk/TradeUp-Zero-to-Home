# Legacy iPad browser preview — do not upload

`01-canli-pazar.png` is an older desktop-browser render at an iPad-shaped
viewport. It is not a capture of the current native binary on an iPad.

Apple rejected the 13-inch iPad storefront screenshots on 2026-09-29 because
they did not reflect the current UI. An iPhone-only target does not remove
previously uploaded iPad media and does not prevent iPad compatibility review.

During the next App Store Connect session, inspect **View All Sizes in Media
Manager** in every localization. Remove obsolete optional iPad media if Apple
allows it for this iPhone-targeted build. If an iPad screenshot is required,
capture the new binary on the matching physical iPad or iOS Simulator and verify
its actual compatibility rendering. Do not stretch an iPhone/web screenshot or
reuse this legacy preview as a substitute.
